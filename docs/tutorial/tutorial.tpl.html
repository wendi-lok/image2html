1　先把软件跑起来

Image2Html 是一个本地网页应用：启动后它会自己开一个服务，并用浏览器打开页面。关掉那个命令行窗口，服务就停了。

1.1　三种启动方式怎么选

方式需要 Python说明
免安装版
推荐给普通用户		 不需要 下载 Image2Html.zip 解压，双击 Image2Html.exe 即可。自带运行环境，换台电脑也能直接用。
一键启动 需要 双击项目里的 run.bat。会自动找到 Python 并启动，无需 pip 安装任何依赖。
命令行 需要 在项目目录执行 python app.py，适合想指定端口或调试的场景。

1.2　免安装版（不需要 Python）

到项目的 Releases 页面下载 Image2Html.zip（约 8.8 MB），解压后你会看到：

{{SVG:ZIP_LAYOUT}}
  1. 双击 Image2Html.exe（或 启动.bat）。
  2. 浏览器会自动打开页面，地址是 http://127.0.0.1:5000。如果没自动打开，手动访问这个地址即可。
  3. 用完关掉那个黑色命令行窗口即停止服务；关不掉就在任务管理器里结束 Image2Html.exe。
不要把 exe 单独拖出来用

_internal 文件夹是程序的一部分（里面是运行环境）。Image2Html.exe 单独拷到别处会起不来。分发时请把整个文件夹一起压缩。

Windows 提示「已保护你的电脑」

这是 SmartScreen 对未签名程序的例行拦截。点「更多信息」→「仍要运行」即可。程序完全在你本机运行，不上传任何数据到第三方。

端口被占用了怎么办

默认用 5000 端口。如果被其他程序占用，程序会自动顺延到 5001、5002……，并在窗口里打印实际地址。以窗口里打印的地址为准。

一个细节：启动后，「API 密钥、图床配置、历史记录」都保存在 exe 同级的 data 文件夹里。换电脑时把这个文件夹一起拷走，配置就还在。

2　速创 API：注册、充值、取密钥

Image2Html 自己不提供画图能力，它调用的是速创 API（wuyinkeji）的 GPT-Image-2 接口。所以你必须先有一个速创账号，并且账号里有额度。

2.1　为什么必须充值

这个接口的免费额度是 0

速创的 GPT-Image-2 接口在接口文档里明确写着「免费额度：无」。它不是「先免费用几次再收费」，而是账户里没有余额/点数，调用就会直接失败。所以「注册完就能白画几张」是不成立的，必须走一次充值。

好在这接口不贵：参考价 0.1 元/张。也就是说充 10 块钱大概能画 100 张，试错成本很低。充值一次之后，余额/点数/次数包用户还不受请求频率和每日次数限制，用起来不会莫名其妙被限流。

2.2　注册账号

打开官网 https://api.wuyinkeji.com/user/register，也可以从首页 api.wuyinkeji.com 右上角的「注册」进入。

注册表单需要填这些：

字段要求
邮箱或手机号二选一，用来收验证码，也是以后的登录账号
验证码点「发送验证码」，填收到的 6 位数字
密码至少 8 位，且必须同时含字母和数字（页面有强度提示）
确认密码再输一遍
邀请码选填。有的话可以拿额外积分奖励，没有就留空

勾选同意《服务条款》和《隐私政策》，点「注册」即可。

2.3　登录控制台

登录地址 https://api.wuyinkeji.com/user/login，提供两种方式：

  • 微信登录：扫码即可，最省事。
  • 账号登录：用刚才注册的邮箱/手机号 + 密码。

登录成功后进入控制台 https://api.wuyinkeji.com/user/。后面要用的三个入口都在这里：

菜单地址用来干什么
订单管理/user/order看余额、看消费记录、充值
密钥管理/user/key创建和管理 API 密钥
VIP / 套餐/user/vip看包月、次数包等更划算的方案

2.4　充值：把钱变成额度

{{SVG:RECHARGE}}
  1. 进控制台，打开「订单管理」 登录后地址栏输入 https://api.wuyinkeji.com/user/order，或从控制台左侧菜单点进去。
  2. 找到余额区，点充值 这一页同时显示「费用明细、当前余额、消费记录」。余额为 0 时先充值。
  3. 选金额并付款 平台支持在线支付（支付宝/微信）。想先试水就充最小额度即可，0.1 元/张，几块钱够画很久。
  4. 回来看余额是否到账 付款后回到「订单管理」，确认余额数字已经变了。没变就刷新页面或稍等一会儿。
  5. （可选）看有没有更划算的套餐 在「VIP / 套餐」页里，次数包和单独包月通常比按张扣余额便宜。用量大的话值得看一眼。
充多少合适

第一次建议先充 10 元（约 100 张）跑通全流程。确认生成效果和你的使用姿势没问题，再考虑买次数包或包月。

2.5　取 API 密钥

  1. 打开「密钥管理」 地址 https://api.wuyinkeji.com/user/key，或从控制台菜单点「密钥管理」。
  2. 创建一个密钥 点新增/创建，按提示起个名字（比如 image2html），便于以后区分用途。
  3. 复制保存 创建后完整密钥只显示这一次，当场复制。建议先粘到记事本里备用。
密钥不要泄露

这个密钥等同于你账户里的钱——别人拿到就能花你的余额。不要发到群里、不要截图发出去、不要提交到代码仓库。一旦怀疑泄露，立刻在「密钥管理」里删除重建。

2.6　填进 Image2Html

回到 Image2Html 页面，点右上角的齿轮图标打开设置，把密钥粘进「API 密钥」输入框，点「保存」。

填完就能用了

保存后关掉设置，回到主界面，输入提示词点「生成图片」即可。不再需要参考图的话，第三章整章都可以跳过。

2.7　计费规则速查

项目说明
计费单价0.1 元/张（按账户余额抵扣），或 10 点/张（按点数抵扣）
免费额度无，账户必须有余额/点数/次数包
扣费时机只有提交生成任务那一次请求计费；之后查询结果不另外收费
计费优先级VIP 专属 → 单独包月 → 次数包 → 点数计费 → 账户余额 → 免费额度（从上往下依次判断）

备注：速创还有别的图像模型（例如 GPT-Image-2.5-flare，参考价 0.3 元/张）。Image2Html 目前对接的是 GPT-Image-2 这一个，单价以 0.1 元/张为准。

3　参考图与图床

3.1　为什么非要图床不可

如果你只是想「输入一句话画张图」，可以跳过这一章。但只要你想上传自己的参考图（图生图、改风格、换背景），就绕不开图床。

原因在于：速创接口的参考图参数 urls 只接受公网能访问到的图片链接。而你在本地上传的图，地址形如 http://127.0.0.1:5000/uploads/xxx.png——这个 127.0.0.1 是「你自己这台电脑」的意思，速创的服务器拿到这个地址，访问到的是它自己那台机器，当然什么都找不到。

所以流程必须是：本地图片 → 上传到图床拿到公网直链 → 把这个直链填进 urls。Image2Html 已经把这步自动化了：你把图拖进窗口，它自动上传、自动换成公网链接，你不需要手动复制粘贴。

{{SVG:HOST_WHY}}

3.2　七个图床怎么选

设置里的「参考图图床」默认是自动选择，会按固定顺序依次尝试，第一张成功就用它。除非你有明确理由，否则保持自动即可。

图床要不要注册国内可直连特点与建议
UAPI
默认首选		可不注册是免注册就能用，但匿名每天只有 10 张。国内直连、速度稳。建议花两分钟注册拿个 Key，之后就顺畅了
PicUI需要是国内图床，注册后在个人中心取 Token。长期用比较稳
SM.MS
已迁至 S.EE		需要一般老牌图床，现已迁移到 S.EE 域名。需要在 S.EE 后台创建 API Token
ImgURL需要是国内图床，要同时填 UID 和 Token 两个值
ImgBB需要否（海外）海外老牌图床，需要在官网申请 API Key
Catbox免注册否（海外）海外兜底，永久保存，但国内网络经常连不上
Uguu免注册否（海外）海外兜底。链接大约 3 小时后失效，只当应急
先注册 UAPI，这一件事就能省掉大部分麻烦

匿名 10 张/天的额度很容易用完。用完之后虽然会自动换到海外图床，但海外的链接有时效（Uguu 约 3 小时），而且国内直连不稳。花两分钟注册 UAPI 拿个免费 Key，就能一直用最稳的那个。

3.3　UAPI（默认，推荐先去注册）

UAPI 是 uapis.cn 提供的 API 平台，它的图片上传接口免注册就能用，所以被设为默认。

免费额度

身份额度
未登录访客1500 积分，但图片上传接口另有每天 10 张的限流
登录用户每月 3500 积分，每月 1 号自动重置，且不受上面那个 10 张限制

取 Key 的步骤

  1. 打开 https://uapis.cn/login 注册并登录 支持常见方式注册，登录后进入控制台。
  2. 进控制台 https://uapis.cn/console 在这里能看到你的用量和额度。
  3. 找到 API Key（页面上叫 uapikey）并复制 UAPI 官方文档里提到的凭证就叫 uapikey，在控制台可以查看/创建。
  4. 粘进 Image2Html 设置 → 参考图图床选「UAPI」→「图床 Token / API Key」粘贴 → 保存。
不填也能用

「图床 Token / API Key」这个框是可选的。留空就走匿名额度（每天 10 张）；填了就不限量。这是全场性价比最高的一次注册。

3.4　PicUI

PicUI（picui.cn）是国内图床，接口采用 Bearer Token 鉴权；不带头就会被当成游客上传，所以想稳定使用建议注册。

  1. 注册：打开 https://picui.cn/register 完成注册。
  2. 登录进个人中心：https://picui.cn/user/dashboard。
  3. 找到 Token：在个人中心（个人设置/接口相关区域）能看到属于你的 API Token，复制它。
  4. 填进设置：参考图图床选「PicUI」，Token 粘进去，保存。

技术上它把 Token 放在 Authorization: Bearer <token> 请求头里调用 https://picui.cn/api/v1/upload。这些细节你不用管，程序已经处理好了。接口有每分钟请求配额，超额会返回 429。

3.5　SM.MS / S.EE

SM.MS 是老牌免费图床，但 2024 年起它的上传接口已经迁移到了 S.EE 域名（旧地址会返回 308 跳转）。所以现在要拿的是 S.EE 的 API Token。

  1. 打开 https://s.ee/ 注册并登录 按 S.EE 官方文档的说法，前提是「一个拥有有效套餐的 S.EE 账号」。
  2. 进入开发者 / API Token 区域，创建一个 Token S.EE 后台有专门的 Token 管理入口（页面上标注为 API Token / Developer），点 Create Token 生成。
  3. 复制这个 Token
  4. 填进 Image2Html：参考图图床选「SM.MS」，Token 粘进去，保存。
程序会把两种写法都试一遍

SM.MS 的老接口和 S.EE 的新接口对鉴权头的格式要求不一致（一个用 Token 原文，一个文档写的是 Bearer）。程序对这两个地址、两种写法一共试四次，哪种能通就用哪种，你不用手动选。

3.6　ImgURL

ImgURL（imgurl.org）是国内图床，它的接口比较特殊：需要同时提供 UID 和 Token 两个值，而且它们是放在请求体里的，不是放在请求头里。

  1. 注册：打开 https://www.imgurl.org/user/register。
  2. 登录后进个人中心：地址是 https://www.imgurl.org/account。
  3. 分别复制 UID 和 Token：这两个值都要。
  4. 填进 Image2Html：参考图图床选「ImgURL」。这时设置面板会多出一个 UID 输入框，把 UID 填进这个新框、Token 填进原来的框，然后保存。
只填 Token 不填 UID 是不会成功的

这两个值必须配对使用。切换图床时留意设置面板里是否出现了额外的 UID 输入框。

3.7　ImgBB

ImgBB 是海外老牌图床，需要 API Key。注意它是海外站点，国内网络直连可能不稳。

  1. 注册：打开 https://imgbb.com/signup 完成注册。
  2. 登录后打开 https://api.imgbb.com/ 登录状态下这个页面会显示属于你的 API Key（也可从 imgbb.com/api 进入）。
  3. 复制 API Key。
  4. 填进 Image2Html：参考图图床选「ImgBB」，Key 粘进「图床 Token / API Key」，保存。

3.8　免注册的海外兜底

还有三个不需要注册的图床，程序把它们放在顺序的最后，属于「实在没辙了」的兜底：

图床说明
Catbox免注册、文件永久保存。但国内网络直连经常失败。
Uguu免注册、上传快。但链接大约 3 小时后就会失效，只适合马上要用的场景。
Telegraph免注册。国内网络通常不可达。
看到「已自动换用 Uguu」该怎么办

这句话的意思是：默认图床（UAPI）没成功，程序换到了 Uguu。图能用，但那张图的链接大约 3 小时后就失效了——如果你过一会儿才去生成，可能就会失败。

正确的处理是：去 UAPI 注册拿一个免费 Key 填进设置。这通常就是「UAPI 匿名额度（每天 10 张）用完了」这一个原因。

3.9　自动降级是怎么跑的

「自动选择」不是随便挑一个，而是有明确顺序的。理解这个顺序，你就能看懂界面上那些提示。

{{SVG:HOST_CHAIN}}

顺序是固定的：

UAPI → PicUI → SM.MS → ImgURL → ImgBB → Catbox → Uguu → Telegraph

其中需要登录的图床，如果没填 Token 会被直接跳过（否则每次都白等一个超时）。第一个成功的就用它，只有全部失败才回退成不可用的本地地址。

这个设计最实用的一点：它会告诉你「换了哪个、代价是什么」

如果降级发生了，界面上会明确写出换成了哪个图床、以及这个图床的代价。不会让你只看到一句笼统的「上传成功」。

4　完整生成流程

4.1　功能分区

区域作用
提示词描述你想要的画面。必填。
宽高比例默认「自动」。可选 1:1、16:9、9:16、4:3、3:4、3:2、2:3、21:9 等共 14 种。
参考图片最多 5 张，可拖拽排序。不填就是纯文生图。
生成图片提交任务。
历史记录折叠面板。记录每次任务的 task_id，点开可随时重新查询结果——因为结果存在速创服务器上，历史记录不会过期。
右上角EN 切换中英文；齿轮打开设置。

4.2　加参考图的三种方式

三种方式殊途同归，都会自动走「上传图床 → 换公网链接」这一步：

  1. 把图片文件拖进窗口任意位置 整个页面会出现一个提示遮罩，松开鼠标就开始上传。拖到「参考图片」区域里也可以。
  2. Ctrl + V 粘贴截图 截图工具截完直接粘贴，适合从其他软件里抓图。不需要先存成文件。
  3. 点「+」选文件，或直接粘贴图片网址 如果你已经有一个公网图片链接，粘到「或粘贴图片链接」里点「添加」即可，这种情况不需要图床。

上传期间图片位置上会显示一个转圈占位符，上传完成后替换成真实图片，并在左下角打上来源图床的徽标（例如 UAPI、Uguu）。如果上传失败，图片会被移除并弹出提示。

4.3　提交与等待

{{SVG:FLOW}}
  1. 填提示词，选比例，点「生成图片」 如果还有参考图在上传中，会被拦下来并提示你等一下——这是为了避免提交残缺的参考图列表。
  2. 程序提交任务，拿到 task_id 这一步是唯一计费的请求。
  3. 自动轮询等待 程序每 24 秒查询一次结果，界面上有倒计时进度条。最多查询 30 次，也就是大约 12 分钟。
  4. 出图后预览、保存、重新生成 结果展示在右侧，可以保存到本地，也可以直接用同一个提示词重新生成一张。
生成时间是不确定的

取决于当时的排队情况，快的几十秒，慢的需要几分钟。进度条在转就说明还在跑，不要重复点「生成图片」——每次提交都是一次新计费。

等太久没出结果但浏览器关掉了？不用重画

展开「历史记录」，找到那条任务点查询即可。任务结果存在速创服务器上，不会因为你关了页面就丢失，重新查询也不额外收费。

4.4　中英文切换与历史记录

右上角的 EN / ZH 按钮切换界面语言，选择会被记住。

「历史记录」面板点开后可以查看每次任务的提示词、task_id 和结果；点 task_id 旁边的复制按钮可以把它抄下来，之后单独查询。

5　出错了怎么查

5.1　按报错信息对照表

你看到的提示原因与处理
提示需要先设置 API 密钥 还没填速创密钥。点右上角齿轮填入并保存。
提交失败，提示余额/额度相关 速创账户没钱了。去「订单管理」确认余额，必要时充值。免费额度为 0，账户没余额就一定失败。
上传参考图后提示「已自动换用 Uguu / Catbox」 默认图床 UAPI 没成功（多半是匿名额度用完了）。图能继续用，但海外链接可能几小时后失效。去 UAPI 注册拿 Key 填进设置即可。
提示「图床均不可用，已回退为本地地址」 所有图床都失败了。此时参考图地址是本地地址，速创服务器抓不到，生成大概率会失败。检查网络，或在设置里为某个图床填上 Token。
提示不支持该图片格式 只接受 jpg / jpeg / png / gif / webp / bmp 六种。其他格式先转换一下。
参考图加不进去 / 提示最多 5 张 上限就是 5 张。删掉一张再试。
浏览器打不开页面 看命令行窗口里打印的实际地址（端口可能不是 5000）。手动访问那个地址。
双击 exe 一闪而过 启动报错了。改用 启动.bat 启动，它会把错误信息留在窗口里。
填了图床 Token 但还是失败 确认图床类型和 Token 是否配套；ImgURL 需要同时填 UID 和 Token；SM.MS 需要 S.EE 的 Token 且账号有有效套餐。

5.2　一个容易被忽略的坑：UA 被拦截

如果你要自己改这个项目、或者自己写脚本调图床接口，有一个坑值得提前知道：

用 Python 默认的 User-Agent 请求某些图床，会被 Cloudflare 直接挡掉

Python 的 urllib 默认会发 Python-urllib/3.x 作为 User-Agent。部分图床（例如 S.EE）前面挂了 Cloudflare，看到这个 UA 会直接返回 403，响应体是一句 error code: 1010——它不是 JSON，看起来很像「接口挂了」，实际只是被 WAF 拦了。

解决办法是发一个普通的浏览器 UA。这一点在 v1.1 里已经修好了。

反过来，如果你看到某个图床「文档里明明能用，自己一调就 403」，先用 curl 再试一次。curl 和浏览器都能通、只有你的脚本不通，那基本就是 UA 或者请求头的问题。
